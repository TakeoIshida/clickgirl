# ClickGirl — ゲーム仕様書

## 概要

女の子キャラクターをタップして売上を稼ぎ、社員を採用・育成しながら会社を大きくしていくクリッカー系放置ゲーム。

- **プラットフォーム**: iOS
- **技術**: Swift / SpriteKit
- **通貨単位**: ✦（スター）※ 実在通貨は使用しない

### GameScene（メイン画面）

#### 縦方向の領域分割

```
┌─────────────────────┐ ← frame.height
│  HUD（120pt）        │   所持✦・収益表示、ナビボタン
├─────────────────────┤ ← frame.height - 120
│                     │
│  メインキャラ表示     │   _nobg PNG を使用
│  幅: frame.width×0.85│   HUDと社員パネルの間に縦中央配置
│  高さ: アスペクト比自動│   最大高さ=(エリア高さ×0.95)で自動縮小
│                     │
├─────────────────────┤ ← y = 210
│  オフィスちびキャラ   │   chibiW=36pt（縦長画像対応サイズ）

├─────────────────────┤ ← y = 210
```

### CityScene（都市開発画面）

#### TopBar

- ゴールドアクセントライン（height=1.5pt）+ グロー層
- 左: ◀ 戻る、中央: 🌆 都市開発、右: 所持✦ / 都市収益

#### 都市ビュー（アイソメトリック、215pt高）

タイル定数:
```
tW = 76pt  // タイル幅
tH = 38pt  // タイル高さ
gox = -19  // グリッド横オフセット（3列中央揃え）
goy = -22  // グリッド縦オフセット（下寄せ）
```

座標変換:
```swift
isoCenter(col, row) = (
    x: (col - row) * tW / 2 + gox,
    y: -(col + row) * tH / 2 + goy
)
```

描画レイヤー（奥→手前）:

| Layer | 内容 |
|-------|------|
| 1 | 空（青グラデーション、cornerRadius=12） |
| 2 | 遠景ビル群（暗青シルエット + 窓ランダム点灯） |
| 3 | 水面（台形パス + 白シマーパルス） |
| 4 | 地面（緑）+ 道路ベース（ダークグレー） |
| 5 | アイソメトリックプロット×6（奥行きソート、col+row 昇順） |
| 6 | 木×6本、街灯×2本 |

各プロットの描画:
1. 道路ダイヤモンド（tW+10、tH+5）
2. 歩道ダイヤモンド（tW-2、tH-1）
3. 建物（3面: 左面/右面/屋根）または 空き地（緑タイル + ＋マーク）

建物描画:
- 建物高さ: `buildingHeight(level) × 0.48`（アイソメトリックスケール）
- 左面（暗め）・右面（さらに暗め）・屋根（フル輝度）の3面構成
- 窓: 左面にパラレログラム補間で配置、ランダム点灯
- 屋根アクセント: タワー=アンテナ+赤点滅ライト、ホテル=プール、モール=ストライプ
- 屋根アイコン: 建物タイプの絵文字
- 屋根グロー: 建物色のパルスリング
- Lv2以上: 金色レベルバッジ（"L2" 等）

ビルのアイソメトリック高さ基準値（`buildingHeight(level:)`）:

| 種類 | baseHeight | heightPerLevel |
|------|-----------|----------------|
| カフェ | 38 | 12 |
| レストラン | 55 | 18 |
| ホテル | 85 | 28 |
| モール | 72 | 22 |
| タワー | 130 | 40 |

## 収益システム

### タップ収益

```
タップ値 = (1.0 + 採用済み社員の収益/秒の合計 × 0.1) × tapMultiplier
```

### 自動収益（毎秒）

```
totalIncomePerSec = (社員収益合計 × incomeMultiplier × officeIncomeMultiplier × floorIncomeMultiplier) + cityIncomePerSec
```

### コンボシステム

- 0.85秒以内に連続タップするとコンボカウント増加
- コンボボーナス: `+10% × (コンボ数 − 1)` （上限 +100%）
- 0.85秒タップなしでリセット

### コスト

| 種別 | コスト |
|------|--------|
| シングル | ✦50,000 |
| 10連 | ✦450,000（1回分お得） |

| レアリティ | 排出率 | 収益ボーナス（カード1枚あたり） |

| N | 60% | +2% |
| R | 30% | +5% |
| SR | 8% | +15% |
| SSR | 2% | +40% |

### 天井

- 10回ごとに **R以上** が確定

### カード演出（めくり）

ガチャ結果はカードの裏面が表示された状態で始まり、プレイヤーが能動的にめくって公開する。

#### 1枚引き
1. カード裏面がポップインで登場
2. ヒント「タップしてめくろう！」が表示される
3. カードをタップ → フリップアニメーションで表面を公開
4. SR/SSR の場合はフラッシュエフェクトが発動
5. ヒントが「タップで閉じる」に切り替わる

#### 10連引き
1. 10枚の裏面が左上から順に波状にポップイン（0.08秒刻み）
2. 「✨ 全てめくる」ボタンと「カードをタップしてめくろう」ヒントが表示される
3. **個別めくり**: 各カードをタップすると1枚ずつフリップ
4. **まとめてめくる**: 「全てめくる」ボタンをタップすると残りを左から順に連続フリップ（0.12秒刻み）
5. 全カードめくり完了後、「全てめくる」ボタンが消えてヒントが「タップで閉じる」に切り替わる

#### カード裏面デザイン
- 深紫背景 + 紫ボーダー、回転する ✨ アイコン、「CLICK GIRL」テキスト（小カードは「CG」）

#### フリップアニメーション仕様
- 前半: 裏面の xScale が 1 → 0（easeIn、0.13秒）
- めくり瞬間: 白いシマー（光）が瞬く
- 後半: 表面の xScale が 0 → 1.08 → 1.0（easeOut + バウンス、0.18秒）

### 10連グリッドレイアウト

**配置: 3+3+3+1**（3列×3行 + 最後の1枚を画面中央）

```
cardW = floor((画面幅 - 24 - 10×2) / 3)
cardH = min(floor(cardW × 1.58), floor((利用可能高さ - 8×3) / 4))
```

| 画面幅 | カードサイズ（目安） |
|--------|------------------|
| 390pt（iPhone 14等） | 115 × 160 pt |
| 375pt（iPhone SE等） | 110 × 153 pt |

- 余白: 左右各 12pt、カード間 10pt、行間 8pt
- 縦位置: 「全てめくる」ボタン領域（下115pt）と上部マージン（65pt）の間でグリッド全体を縦中央寄せ
- 最終10枚目は単独で画面横中央に配置

### カード収益倍率

```
cardIncomeMultiplier = 1.0 + Σ(rarity.incomeBonus × 所持枚数)
```

   - 例: `airi_5.jpg`, `hana_7.jpg`
3. 以下のフォルダに配置:
   ```
   swiftgame/clickgirl/downloaded_images/
   ```
4. Claude Code に「インポートして」と依頼
   → `import_images.py` が背景除去・xcassets登録を自動実行

## バグ修正履歴

### 2026-04-23

#### AdMob クラッシュ（EXC_BAD_ACCESS / EXC_I386_GPFLT）

**症状:** 起動直後に Thread 4/8 (concurrent) で `GADApplicationVerifyPublisherInitializedCorrectly` が NSException を投げてクラッシュ。

**原因:** `GENERATE_INFOPLIST_FILE = YES` + `INFOPLIST_KEY_GADApplicationIdentifier` のビルド設定では AdMob SDK v13 が `GADApplicationIdentifier` を Info.plist から読み取れない。

**修正内容:**
1. `AppDelegate.swift` を変更 — `MobileAds.shared.start()` を起動直後に即時呼び出し、ATTracking は 1 秒後に非同期で別途リクエスト
2. `ClickGirl/Info.plist` を手動作成 — `GADApplicationIdentifier` を直接記載（テスト ID: `ca-app-pub-3940256099942544~1458002511`）
3. `GENERATE_INFOPLIST_FILE = NO` に変更、`INFOPLIST_FILE = ClickGirl/Info.plist` を明示

**本番リリース時の注意:** `Info.plist` の `GADApplicationIdentifier` を実際の AdMob App ID に変更すること。

---

#### CharSelectScene キャラ画像の歪み

**症状:** キャラ選択画面のカード内キャラ画像が正方形に潰れて歪んで表示される。

**原因:** `SKTexture(imageNamed:)` はシーン遷移直後に `size()` が `(1, 1)` を返すことがある。

**修正内容（`CharSelectScene.swift` `makeCard` 関数）:**
- `UIImage(named:)` でアスペクト比を正確に取得
- 高さが上限を超えた場合、幅も縮小してアスペクト比を保持（aspectFit）
